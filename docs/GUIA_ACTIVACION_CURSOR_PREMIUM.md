## 🚀 **Pasos para Activar Cursor Premium:**

### **Paso 1: Activar Premium**
1. Abrir Cursor
2. Ir a **Settings** (⚙️)
3. Buscar **"Premium"** o **"Subscription"**
4. Hacer clic en **"Upgrade to Premium"**
5. Completar el proceso de pago ($20-30/mes)

### **Paso 2: Configurar Español**
1. Ejecutar el script que creé:
```powershell
powershell -ExecutionPolicy Bypass -File cursor-setup.ps1
```

2. O configurar manualmente en settings.json:
```json
{
  "cursor.language": "es",
  "cursor.chat.language": "es",
  "github.copilot.chat.localeOverride": "es"
}
```

### **Paso 3: Importar Proyecto AltaMedica**
1. Abrir Cursor
2. **File → Open Folder**
3. Seleccionar tu carpeta `altamedicadev`
4. Esperar a que Cursor analice todo el codebase

### **Paso 4: Configurar Contexto Médico**
1. Abrir **Cursor Chat** (Ctrl+L)
2. Escribir:
```
"Configura el contexto para un proyecto médico llamado AltaMedica con Next.js, TypeScript, Firebase, y múltiples APIs médicas que requieren compliance HIPAA"
```
