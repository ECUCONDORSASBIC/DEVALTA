## ⚡ Comenzar en 3 Pasos

### 1️⃣ **Ejecutar el Sistema**
```bash
# Opción A: Script automático
iniciar-sistema-altamedica.bat

# Opción B: Comando manual
cd C:\Users\Eduardo\Documents\devaltamedica\mcp-servers
node enhanced-multi-agent-mcp.js
```

### 2️⃣ **Copiar un Prompt**
Abre [PROMPTS_AUTOMATIZADOS_ALTAMEDICA.md](./PROMPTS_AUTOMATIZADOS_ALTAMEDICA.md) y copia cualquier prompt

### 3️⃣ **Pegar y Observar**
Pega el prompt y observa cómo 18 agentes especializados trabajan colaborativamente
