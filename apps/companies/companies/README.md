# Proyecto Companies - Next.js

Este proyecto es una aplicación desarrollada con [Next.js](https://nextjs.org/), diseñada para la gestión de compañías dentro del ecosistema Altamedica.

## Requisitos Previos

- Node.js >= 18.x
- npm, yarn, pnpm o bun

## Instalación

1. Clona el repositorio y navega a esta carpeta:
   ```bash
   git clone <REPO_URL>
   cd apps/companies
   ```
2. Instala las dependencias:
   ```bash
   npm install
   # o
   yarn install
   # o
   pnpm install
   # o
   bun install
   ```

## Ejecución en Desarrollo

Inicia el servidor de desarrollo:
```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.

## Estructura Principal
- `app/` - Páginas y rutas principales de la aplicación.
- `components/` - Componentes reutilizables.
- `public/` - Recursos estáticos (imágenes, etc).
- `styles/` - Archivos de estilos CSS/SCSS.

## Despliegue

Para desplegar la aplicación, consulta la [documentación oficial de Next.js](https://nextjs.org/docs/app/building-your-application/deploying) o utiliza plataformas como Vercel.
