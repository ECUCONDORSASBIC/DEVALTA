# @altamedica/medical-cache

Gestor de caché médico optimizado y reutilizable para Altamedica.

## Uso

```ts
import { medicalCache } from '@altamedica/medical-cache'

// Ejemplo de uso
const data = medicalCache.get('patients', 'id-123')
```

## Descripción
Este paquete proporciona una implementación centralizada y eficiente de caché para datos médicos, con soporte para métricas, cumplimiento HIPAA y estrategias avanzadas de invalidación.

## ESM
Este módulo está escrito y exportado como ESM (ECMAScript Modules).
